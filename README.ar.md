## البدء السريع

1. انسخ **مجلداً كاملاً واحداً** إلى مجلد skills الخاص بـ Codex: [المهارة الإنجليزية](skills/equity-research-report-en/) أو [المهارة الصينية](skills/equity-research-report-zh/).
2. أعد تشغيل Codex، ثم حدد الشركة وتاريخ التقييم والموعد النهائي للمعلومات ومنطقته الزمنية والجمهور والنطاق وصيغ التسليم.
3. مثال على الطلب:

   > استخدم ‎$equity-research-report-en لدراسة الشركة المحددة وتقييمها وفق المعلومات المتاحة حتى الموعد المذكور. استخدم المصادر الرسمية الأصلية والقالب المقدم، وسلّم نموذجاً قابلاً لإعادة الحساب وتقريراً يوضح أهم الحساسيات والشروط التي تغير النتيجة.

الصفحات اليابانية والكورية والعربية ترجمات لهذه المقدمة؛ تعليمات المهارتين متاحة بالإنجليزية والصينية.

## سير العمل

1. حدد مهمة البحث وأنشئ مساحة عمل جديدة.
2. اجمع المصادر الأصلية وسجل منشأها وطابق البيانات المالية وتعريفاتها.
3. كوّن أحكاماً بحثية، واختر الطرق المناسبة، وابنِ توقعات وتقييماً قابلين لإعادة الحساب.
4. اكتب التقرير وافحص ارتباط الأرقام بالأدلة والصفحات بعد عرضها.
5. سلّم التقرير والنموذج والمدخلات وسجلات المصادر ونتائج المراجعة المطلوبة، مع توضيح النواقص الجوهرية وشروط الاستنتاج.

يستند هذا النهج إلى خبرة البحث والمراجعات البشرية لتقرير شركة تشانغجيانغ للطاقة. أرقام ذلك المثال ونموذجه القطاعي وهيكل فصوله ليست افتراضات افتراضية للشركات الأخرى.

## المخرجات

تحتوي كل مهارة على خمسة مراجع للبحث والنمذجة والكتابة والتسليم ودراسة حالة تشانغجيانغ، وثلاثة برامج مساعدة تعتمد على مكتبة Python القياسية فقط. تنشئ البرامج مساحة العمل، وتحفظ عناوين URL العامة المقدمة وسجلات المحاولات الفاشلة، وتفحص العلاقات القابلة للتحقق آلياً. توجد الأوامر وصيغ السجلات في `references/delivery.md` داخل كل مهارة.

لا تجري البرامج البحث أو تقييم الشركة أو كتابة التقرير كاملاً بصورة آلية. الحصول على المصدر لا يعني التحقق منه أو قبوله في النموذج؛ وتتطلب الأحكام الاقتصادية وجودة الصفحات مراجعة فعلية. لم تثبت قدرة المشروع على إنجاز البحث بالكامل دون إشراف.

## الأسئلة الشائعة

**أي إصدار أختار؟** اختر المجلد الصيني أو الإنجليزي وفق لغة التعليمات المطلوبة؛ يمكن تثبيت كل منهما مستقلاً عن الآخر.

**ما المعلومات المطلوبة؟** حدد الشركة والغرض على الأقل. ويساعد تحديد تاريخ التقييم والموعد النهائي للمعلومات ومنطقته الزمنية والجمهور والنطاق والقالب وصيغ التسليم.

**هل يمكن استخدام النتيجة دون مراجعة؟** لا. راجع المصادر والافتراضات والحسابات والأحكام وصفحات التقرير النهائية. نجاح الفحص الآلي لا يثبت صحة الافتراضات الاقتصادية أو الاستنتاج الاستثماري.

## التحقق

من جذر المستودع:

```bash
python -m unittest discover -s tests -v
```

تستخدم الاختبارات مجلدات مؤقتة وخادم HTTP محلياً، ولا تختبر الوصول إلى شركات فعلية أو خدمات تتطلب مصادقة، ولا تثبت إنتاج التقارير دون إشراف. لا يتضمن المستودع التقرير الأصلي كاملاً أو أوراق العمل الخاصة أو حزمة المصادر الأصلية.
