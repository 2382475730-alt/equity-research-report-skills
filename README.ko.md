## 시작하기

1. [영어 스킬](skills/equity-research-report-en/) 또는 [중국어 스킬](skills/equity-research-report-zh/)의 **전체 폴더 하나**를 Codex skills 디렉터리에 복사합니다.
2. Codex를 재시작하고 회사, 평가일, 정보 기준 시점과 시간대, 독자, 범위 및 산출물 형식을 지정합니다.
3. 요청 예시:

   > $equity-research-report-en을 사용해 지정 기업을 정해진 기준 시점에 맞춰 분석하고 가치평가해 주세요. 공식 원본과 제공한 양식을 사용하고, 재현 가능한 모델과 보고서, 주요 민감도와 결론을 바꿀 조건을 제시해 주세요.

일본어, 한국어, 아랍어 페이지는 소개 문서의 번역입니다. 스킬 실행 지침은 영어와 중국어로 제공됩니다.

## 작업 과정

1. 분석 범위를 정하고 새 작업 공간을 만듭니다.
2. 원본 자료를 확보하고 출처를 기록하며 재무 수치와 정의를 대조합니다.
3. 연구 판단을 내리고 적절한 방법을 선택해 재현 가능한 예측과 가치평가를 구축합니다.
4. 보고서를 작성하고 수치와 근거의 연결 및 렌더링된 페이지를 확인합니다.
5. 요청된 보고서, 모델, 입력값, 출처 기록 및 검토 결과를 제공하고 중요한 누락과 결론의 조건을 설명합니다.

이 과정은 창장전력 보고서의 연구와 사람의 수정 경험을 바탕으로 합니다. 해당 사례의 수치, 산업 모델, 장 구성은 다른 기업의 기본값이 아닙니다.

## 결과물

각 스킬에는 조사, 모델링, 작성, 납품, 창장전력 사례에 관한 참고자료 다섯 개와 Python 표준 라이브러리만 사용하는 보조 스크립트 세 개가 포함됩니다. 스크립트는 작업 공간 초기화, 지정된 공개 URL과 실패 기록 보존, 기계로 검증 가능한 관계 확인을 수행합니다. 명령과 기록 형식은 각 스킬의 `references/delivery.md`를 참조하세요.

스크립트는 검색, 기업 가치평가 또는 전체 보고서 작성을 자동으로 수행하지 않습니다. 자료 확보가 검증이나 모델 채택을 뜻하지는 않으며 경제적 판단과 페이지 품질은 실질적인 검토가 필요합니다. 전체 과정의 무인 실행은 검증되지 않았습니다.

## 자주 묻는 질문

**어떤 버전을 설치하나요?** 지침 언어에 따라 중국어 또는 영어 폴더를 선택하세요. 두 버전은 서로 의존하지 않습니다.

**무엇을 제공해야 하나요?** 최소한 회사와 용도를 알려주세요. 평가일, 정보 기준 시점과 시간대, 독자, 범위, 양식 및 산출물 형식도 도움이 됩니다.

**검토 없이 결과를 사용할 수 있나요?** 아니요. 자료, 가정, 계산, 판단과 최종 페이지를 검토해야 합니다. 자동 검사 통과는 경제적 가정이나 투자 결론을 증명하지 않습니다.

## 검증

저장소 루트에서 실행합니다.

```bash
python -m unittest discover -s tests -v
```

테스트는 임시 디렉터리와 로컬 HTTP 서버를 사용합니다. 실제 발행사나 인증 서비스 접근 또는 무인 보고서 생산은 검증하지 않습니다. 원본 보고서 전체, 비공개 작업 자료 및 원본 자료 모음은 저장소에 포함되지 않습니다.
