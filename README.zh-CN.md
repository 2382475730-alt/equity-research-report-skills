# 上市公司研究与估值报告技能

本项目提供中文、英文两个可独立安装的Codex skill，把公开资料获取、财务核对、研究判断、预测与估值、报告写作和可验证交付连接为完整工作流程。

它来自长江电力报告的多轮研究与人工修订经验，重点是让准确数据形成可解释判断，并让报告服务读者。它没有把原报告的数值、行业模型或章节数变为通用默认值。

## 选择版本

- 中文：`skills/equity-research-report-zh/SKILL.md`
- 英文：`skills/equity-research-report-en/SKILL.md`

每个目录自带五份参考和三个Python标准库辅助脚本。两版互不依赖，安装时复制所选完整文件夹到你的Codex skills目录即可。

示例请求：

> 使用 $equity-research-report-zh 为指定上市公司完成截至某时点的研究与估值报告。按所给模板交付报告和可复算模型，从官方原件采集资料，给出明确判断、主导敏感性及会改变结论的条件。

使用前按任务填写公司、时点、范围、读者和输出要求；原件取得成功不会自动获得模型采用资格。辅助工具只检查可机器验证的关系，经济解释和页面质量要实质审阅。

## 目录

`data-research.md`处理来源、期间/版本、口径和研究判断；`modeling.md`处理预测、资本成本、终值和权益；`writing.md`处理反复堆证据和声明；`delivery.md`定义台账与验收；`changjiang-case.md`记录历史案例的优点及残留问题。

脚本初始化研究目录、留存指定公开URL并保存失败、检查来源/数字绑定/哈希/审阅记录。具体命令在各版交付参考中。它们不是完整研究agent，不自动搜索、估值或撰写整份报告。
