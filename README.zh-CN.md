## 快速开始

1. 将以下**一个完整文件夹**复制到 Codex 的 skills 目录：
   - [中文技能](skills/equity-research-report-zh/)
   - [英文技能](skills/equity-research-report-en/)
2. 重启 Codex，使其发现技能。提供公司、估值日、信息截止时点及其时区、读者、研究范围和交付格式。
3. 例如：

   > 使用 $equity-research-report-zh 为指定上市公司完成截至指定时点的研究与估值报告。使用官方原件，遵循给定模板，交付可复算模型和报告，说明关键敏感性及会改变结论的条件。

日文、韩文和阿拉伯文页面是本介绍的翻译；可执行的技能指令目前提供中文和英文。

## 工作流程

1. 明确研究任务，初始化新的工作目录。
2. 获取原始资料、记录来源，并核对财务数据与口径。
3. 形成研究判断，选择适合的方法，建立可复算的预测与估值模型。
4. 撰写报告，检查数字绑定、支持证据和渲染后的页面。
5. 交付所需报告、模型、输入、来源记录及审阅结果，说明重大缺口和结论条件。

流程吸收了长江电力报告的研究与人工修订经验，其数值、行业模型和章节结构不是其他公司的默认设置。

## 交付内容

每个技能包含研究、建模、写作、交付和长江电力案例五份参考，以及三个仅使用 Python 标准库的辅助脚本。脚本用于初始化工作区、留存指定公开网址及失败记录，并检查可机器验证的关系。命令和台账格式见各技能的 `references/delivery.md`。

脚本**不会**自动搜索、完成公司估值或撰写完整报告。取得资料不等于核实资料或将其纳入模型；经济判断和页面质量需要实质审阅。本项目尚未证明可以无人值守地完成全流程研究。

## 常见问题

**应该安装哪个版本？** 按技能指令语言选择中文或英文文件夹；两版可独立安装，互不依赖。

**需要提供什么？** 至少说明公司和用途；估值日、信息截止时点及其时区、读者、范围、模板和交付格式有助于界定任务。

**结果可以不经审阅直接使用吗？** 不可以。应检查资料、假设、计算、判断和最终渲染的报告。自动检查通过不能证明经济假设或投资结论成立。

## 验证

在仓库根目录运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时目录和本地 HTTP 服务，不验证真实公司或需要登录的服务，也不能证明无人值守的报告生产能力。仓库不包含原报告全文、私人底稿及原始资料包。
