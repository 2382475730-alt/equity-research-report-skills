# 株式調査・バリュエーションレポート技能

### 一次資料から再現可能な評価と読みやすいレポートへ

上場企業の調査に使える、独立してインストール可能な中国語・英語の Codex スキルです。

[はじめに](#はじめに) · [ワークフロー](#ワークフロー) · [成果物](#成果物) · [よくある質問](#よくある質問) · [検証](#検証)

</div>

## はじめに

1. [英語版](skills/equity-research-report-en/)または[中国語版](skills/equity-research-report-zh/)の**フォルダー全体**を Codex の skills ディレクトリにコピーします。
2. Codex を再起動し、企業、評価日、情報の締切日時とタイムゾーン、読者、範囲、納品形式を指定します。
3. 依頼例：

   > $equity-research-report-en を使い、指定企業の調査と評価を指定時点の情報に基づいて行ってください。公式一次資料と指定テンプレートを使い、再現可能なモデルとレポート、主な感応度、結論が変わる条件を示してください。

日本語・韓国語・アラビア語のページは紹介文の翻訳です。スキルの実行指示は英語と中国語で提供しています。

## ワークフロー

1. 調査条件を定め、新しい作業領域を作成します。
2. 一次資料を取得し、出所を記録して財務数値と定義を照合します。
3. 調査判断を形成し、適切な手法を選び、再現可能な予測と評価を構築します。
4. レポートを作成し、数値と根拠の対応、レンダリング後のページを確認します。
5. 指定されたレポート、モデル、入力、資料記録、レビュー結果を納品し、重要な不足と結論の条件を説明します。

この手順は長江電力レポートの調査と人手による改訂から得た経験に基づきます。事例の数値、業種モデル、章構成は他社の既定値ではありません。

## 成果物

各スキルには調査、モデル、執筆、納品、長江電力の事例に関する五つの参考資料と、Python 標準ライブラリだけを使う三つの補助スクリプトがあります。スクリプトは作業領域の初期化、指定された公開 URL と失敗記録の保存、機械的に検証できる関係の確認を行います。コマンドと台帳形式は各スキルの `references/delivery.md` を参照してください。

スクリプトは自動検索、企業評価、レポート全体の執筆を行いません。資料の取得は検証やモデルへの採用を意味せず、経済的判断とページ品質は実質的なレビューが必要です。無人での全工程の実行は実証されていません。

## よくある質問

**どちらをインストールしますか？** 指示の言語に合わせて英語版または中国語版を選んでください。両者に依存関係はありません。

**何を指定しますか？** 少なくとも企業と用途を指定してください。評価日、情報の締切日時とタイムゾーン、読者、範囲、テンプレート、形式も役立ちます。

**レビューなしで利用できますか？** いいえ。資料、仮定、計算、判断、最終ページを確認してください。自動チェックの成功は経済的仮定や投資判断の正しさを保証しません。

## 検証

リポジトリのルートで実行します。

```bash
python -m unittest discover -s tests -v
```

テストは一時ディレクトリとローカル HTTP サーバーを使用します。実際の発行体や認証付きサービスへのアクセス、無人でのレポート作成は検証しません。原レポート全文、非公開の作業資料、資料パックは含まれていません。
