# 原始资料与研究落地

## 从研究问题安排采集

先画出经营链和权益链。经营链覆盖量、价、成本、税、资本支出和营运资本；权益链覆盖现金、投资、债务、少数权益及其他经济权利。把研究问题变成资料任务：要验证的论点、所需字段、首选原件、作用于哪个预测变量、缺失会怎样影响结论。优先获取能改变结论的材料。

| 研究问题 | 首选原件 | 需要得到的研究结果 |
|---|---|---|
| 公司实际赚什么钱 | 财报分部、业务披露、结算信息 | 业务范围、收入和利润驱动，不重复计入分部与子公司 |
| 优势是否有经济价值 | 同业披露、资源/许可、运维与客户资料 | 相对优势、对量价成本的传导及成立条件 |
| 增长能否兑现 | 批准文件、项目预算、建设进展、收费机制 | 投资→投产→收入→现金的时间线与归属 |
| 利润是否能变成股东现金 | 现金流、债务、股利、关联交易、权利安排 | 利润与现金差异、融资缺口、可分配范围 |
| 现价如何解释 | 同日行情、当时公开的盈利、资本成本原件 | 同口径估值比较、市场隐含条件 |

获取渠道按问题选择：中国上市公司使用发行人投资者关系、交易所/巨潮原公告，统计和政策使用原发布部门；海外业务追到当地发行人、监管或交易所。行情供应商可作入口或经说明的代理，不能假称官方。美股结构化接口可参考[SEC官方API说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)，仍检查期间、单位和申报版本，不将API汇总值自动视作可比较的全部分部。

## 获取与失败处理

搜索定位 → 打开原件 → 下载/留存 → 提取 → 核对 → 决定采用。扫描件用OCR后对重要数字回看页面；HTML表格、结构化API和PDF保留原文/响应及定位。结果缓存按来源、版本和截止边界识别，避免每轮无差别重新下载。

同一URL可能改变内容，保存最终响应地址、下载时点、SHA256和版本线索。下载失败尝试站内IR索引、公告号、监管副本或用户本地原件；适当尝试后记载具体缺项，继续可独立完成的研究。登录、订阅或权限缺项需要用户提供相应访问，不能声称已取得受限资料。

成功下载不是事实核验；找到事实不代表适合进入模型。来源是否可靠、披露是否在截止前、字段定义是否合适、采用是否合理，要分别判断。

## 两种时间用途

- 当前截至时点的经营趋势：可以使用截止前最新重述的可比数，明确版本和范围。
- 历史逐时点研究、PE和回测：使用每个历史时点当时已公开的数据，不回填之后的重述或实际结果。
- 报告期间、首次公开时间、下载时间分别记录；估值日当天只有日期、没有时分，且无法确定是否在截止前的来源，保留未决或排除。
- 后下载的旧原件可用，但应能证明其截止前已公开的版本。证明不了版本时说明适用范围，不能仅看文件标题年份。

## 字段核对

原值提取至少保留字段ID、原始数值和单位、标准化数值和单位、期间、币种、合并范围、原件ID及页码/表行/条款。明确PDF文件页序与印刷页码。

重点检查：发电量/售电量、含税/净价、集团/子公司、经营/投资、归母/少数、存量余额/当期流量、项目预算/已确认成本/尚需付款、账面值/公允价值。例：预算减在建账面成本可作工程量代理，但不能自动叫剩余现金付款。

用同原件内部加总、跨表勾稽和重要原件复查核对关键字段。冲突记录双方值、版本差异、选取理由、受影响输出；不能通过取均值消除冲突。数值换单位必须实际计算：元÷1亿→亿元，MW×0.1→万千瓦，GWh÷100→亿千瓦时。单位例子按物理定义复查，不能只改表头。

## 从事实走向判断

每个主要论点写一张工作卡：研究问题；支持与反对证据；经济机制；模型变量；预测方向与幅度；影响范围；最强替代解释；会改变判断的观察值。正文不必照搬卡片结构。

例：电力需求增长支持消纳，售电量又受来水和调度约束，因此不把宏观用电增速直接设为公司收入增速。价格、售电量和利用率分别进入模型；若结算净价走弱，需求增长与利润下降可以同时发生。

实质缺项采用四类处理：

1. 可补事实：补查原件或校准口径。
2. 合理可估：采用有依据的代理/范围，说明为什么选基准；不得伪装成已披露事实。
3. 足以影响结论：计算敏感性、情景或反转阈值，说明什么情况下判断变化。
4. 权利或范围根本未定：保持未知/条件公式，判断仅覆盖已建立范围；未知不等于零，也不证明某项负债存在。

研究结果可以是明确的积极、中性或负面判断，也可以是“经营优势成立，但当前价格缺少足够安全边际”。给出主张和依据，不能仅写“存在不确定性”。无根据的概率、精确范围和门槛不得捏造。
