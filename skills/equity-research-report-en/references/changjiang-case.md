## Retain improvements and correct residual weaknesses

The final report's structure and prose are useful without making it a flawless template. The October 11 audit had a different artifact hash, so it supplies leads rather than automatically applying to the designated final file. The following residuals were located directly in that file:

- Historical trends retain original 2023 figures rather than explaining later restatement versions. Current comparable trends and historical point-in-time data have different version rules.
- Cash from operations less long-asset payments is shown as RMB420.75 hundred millions. The saved review's original-precision subtraction yields 420.7445871112, rounding to 420.74. Recheck originals before changing the actual report and apply one rounding policy.
- Peer TTM adds/subtracts rounded basic EPS, while the subject uses current shares. Arithmetic consistency does not establish comparable definitions.
- Some added management, overseas, and AI facts are not fully connected to the index; the S19 clause locator remains inconsistent with the saved source review. A sourced fact and a reader-verifiable citation are separate requirements.

- The first two tables lack separate numbered captions and later numbering starts at Table 4. Complex formulas are text rather than native mathematics. Improve these where the delivery format calls for it.
